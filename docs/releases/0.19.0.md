  a slowed reciprocal pump animation, eight guided steps and ten quiz questions.
- Added its model-rendered icon and complete English / Indonesian learning
  content. The catalog now contains 29 objects.
- Preserved the existing app branding, four Android ABIs, production AdMob
  units, delayed measurement, consent flow and billing configuration.
