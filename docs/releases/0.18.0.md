# Cutaway 0.18.0 — ASO refresh, localization, and production bundle

Android versionCode: **23**. Package: `com.cutaway.explorer`.

## Release scope

- Renamed the app to **Cutaway: How Things Work 3D** with the Indonesian
  listing **Cutaway: Cara Kerja Benda 3D**.
- Added a premium graphite/copper visual identity, refreshed launcher/splash
  assets, a new Play icon, and localized feature artwork.
- Added canonical English and Indonesian store copy, eight real app captures
  per locale, release notes, and a recorded AI-asset declaration for the
  generated visual assets.
- Kept the existing YouTube preview and the existing AdMob production units.
  Android initializes UMP consent before requests, delays measurement until
  consent state is known, and exposes privacy options in Settings.
- Production targeting is configured for 177 countries/regions (including
  Rest of World) and the release is submitted as a full rollout.
