# Brand artwork prompt record

These prompts document the original brand artwork used by the 0.18.0 listing. The
artwork was generated with the built-in image generation tool and then exported
deterministically by `tools/build-brand-premium.mjs`. The screenshots themselves
are captures of the running app, not generated UI.

## Play Store icon master

> Logo-brand production artwork for an Android education app called Cutaway: a single precision-engineered white porcelain cutaway cube/hexagonal shell in a three-quarter isometric view, one broad quarter removed to reveal coherent copper-orange inner layers and a dark steel core. Simple, legible silhouette at small size, physically plausible geometry, crisp premium studio lighting, graphite-black background, restrained copper accent, no floating fragments, no tiny gears, no text, no letters, no watermark, no tile, no neon. Center the object inside a 60% safe mask with generous breathing room. Square 1024px composition.
